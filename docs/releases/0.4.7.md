## Player-facing changes

- global scalable action prompt strip across gameplay and core menus;
- active prompts follow the last meaningfully used input device;
- keyboard/mouse prompts use the real HORSEBOUND bindings;
- Xbox, PlayStation, Steam Deck, Nintendo and generic controller label families;
- Nintendo keeps the A/B/X/Y labels supplied by the standardized controller mapping and adds L/R/Minus terminology;
- stick drift does not switch the visible prompt family;
- gameplay header derives the current build from packaged manifest metadata instead of a hardcoded version;
- save-slot cards scale from the 1280×800 design surface;
- save-slot text remains readable with 150% UI scale;
- occupied-slot overwrite confirmation remains controller accessible.

## Architecture

- semantic `PromptAction` values are independent of physical keys/buttons;
- `InputGlyphCatalog` owns keyboard/controller mappings;
- `ControllerGlyphFamily` classifies standardized SDL controller names;
- `InputActivityTracker` receives meaningful activity from gameplay and menu adapters;
- `PromptOverlay` is rendered once at the application layer instead of duplicated across screens;
- controller-family detection safely falls back to Generic in headless unit tests.

## Steam readiness

- added a controller-only launch-to-exit smoke-test contract;
- test route covers Settings, ranch slots, gameplay, save/restart, disconnect/reconnect and 1280×800 readability;
- manual save is visible in gameplay prompts for F5, View, Share and Minus families;
- Nintendo face-button semantics remain subject to physical-device verification before release claims;
- no Steam Deck Verified claim is made without physical Deck testing and Valve review.
