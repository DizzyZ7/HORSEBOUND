## Player-facing Homestead loop

The persistent 0.5.0 domain is now connected to the active ranch.

- visible eight-slot hotbar;
- number keys 1–8 and numpad 1–8 select slots;
- controller D-pad Left/Right selects slots;
- the remappable Build action enters placement mode and confirms construction;
- keyboard brackets or controller D-pad Up/Down cycle structure blueprints;
- R or controller D-pad Left/Right rotates the preview in 15-degree steps;
- placement snaps to a 0.5 metre grid;
- Escape / controller Back cancels placement instead of leaving the ranch;
- valid previews are green and invalid previews are red.

Placement rejects:

- lake positions;
- world boundaries;
- steep terrain;
- overlapping Homestead structures;
- recipes the player cannot currently afford.

## Structures

The active world can now render and persist provisional stylized models for:

- Fence;
- Gate;
- Feeder;
- Water Trough;
- Hay Storage;
- Chest;
- Stable Stall.

Feeder, Water Trough and Hay Storage accept their matching resource when the player stands nearby, selects that resource in the hotbar and uses Interact.

Current honest limitations:

- Chest has no inventory window yet;
- Gate does not open/close yet;
- new structures are placement obstacles for other structures but do not yet block player or horse movement;
- provisional primitive models will later be replaced by production GLB assets.

Those UX and physical-world features are scheduled for 0.5.2 rather than being falsely advertised as complete.

## Horse care

Horse hunger, thirst and energy now update during live fixed-step gameplay.

- activity drains needs gradually;
- gallop drains faster;
- tamed horses consume nearby stored Hay automatically;
- tamed horses drink from nearby Water Troughs automatically;
- an idle horse near a Stable Stall recovers energy faster;
- nearest-horse needs are visible in the ranch HUD;
- automatic care produces visible feedback.

The rates remain forgiving. Infrastructure reduces repetitive work instead of creating a punishing survival timer.

## New-ranch materials

New ranches receive enough Stone to make the first Water Trough obtainable after gathering additional Wood. Older saves are never silently granted or stripped resources.

## Save lifecycle

Every save route is enriched with current Homestead state:

- manual save;
- autosave;
- pause-menu save;
- application backgrounding;
- Save & Main Menu;
- screen disposal during a clean exit.

The save transformer combines live player/horse state from the existing ranch renderer with:

- current hotbar selection;
- placed structures and transforms;
- stored feed/water units;
- horse hunger, thirst and energy.

Legacy fences remain visible exactly once and are merged into the v4 structure contract without duplicate rendering.

## Architecture

`HomesteadRanchScreen` wraps the validated legacy ranch presentation while owning the new Homestead presentation and persistence bridge.

- `RanchSessionScreen` generalizes pause/resume/save lifecycle;
- `GameSessionCapture` exposes the real session through a scoped construction bridge;
- `SaveService` uses an owner-scoped transformer so a stale screen cannot clear a newer session;
- `LivingRanchTelemetryAdapter` isolates temporary access to legacy actor/camera data;
- domain code remains independent of reflection and libGDX rendering;
- the adapter is temporary until the legacy screen is split into explicit controllers/renderers.

## Steam and controller readiness

- the complete Homestead runtime must exist inside the packaged JAR;
- controller D-pad activity changes the active prompt family;
- keyboard Homestead actions restore keyboard prompts;
- pause, input settings and key binding screens preserve the live wrapped ranch;
- the install image remains free of saves, settings, logs and local Steam configuration;
- Steam Deck Verified is not claimed before physical hardware, Proton and Valve review.
