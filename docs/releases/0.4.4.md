# HORSEBOUND 0.4.4 — Controller Foundation

Created by **Dimash Janibekov (DizZyZ7)**.

## Purpose

This release establishes the first controller path across gameplay and the core menu flow while keeping keyboard and mouse support intact.

## Runtime

- official `gdx-controllers` core and desktop backend 2.2.4;
- standardized controller mappings;
- Jamepad desktop native runtime bundled in the self-contained JAR;
- safe controller hot-plug and disconnect recovery;
- radial analog dead zones;
- mixed keyboard/mouse and gamepad commands;
- last-meaningful-device prompt tracking.

## Gameplay bindings

- Left Stick: move / steer;
- Right Stick: camera;
- A: jump;
- X: interact;
- Y: mount / dismount;
- L1: build;
- R1: sprint / gallop;
- Back / View: manual save;
- Start / Menu or B: pause / back.

## Menu flow

The main menu, ranch slots, overwrite confirmation and Settings support D-pad/Left Stick navigation, A confirm and B back.

## Tests

- radial dead-zone behavior;
- analog movement and look mapping;
- semantic button edges;
- disconnect/reconnect behavior;
- mixed keyboard/controller input;
- active prompt switching;
- controller menu navigation;
