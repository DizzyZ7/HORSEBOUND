## True pause

- Pause opens a dedicated screen instead of immediately returning to the main menu;
- the current ranch remains alive in memory and simulation does not advance;
- Resume returns to the same world object without regeneration or reload;
- Save Game persists progress without leaving the session;
- Save & Main Menu saves and disposes the world cleanly;
- backgrounding the application from pause or input settings saves the suspended ranch.

## Input and accessibility profile

Input configuration is stored separately at:

```text
%APPDATA%\HORSEBOUND\input.properties
```

It is intentionally separate from display `settings.properties` and ranch `.hbs` saves.

Available options:

- invert vertical camera;
- movement stick dead zone;
- camera stick dead zone;
- Hold or Toggle sprint/gallop;
- optional controller rumble;
- rumble strength;
- reset to safe defaults.

Changes apply to the live input adapters without recreating the ranch.

## Keyboard rebinding

The player can rebind:

- forward, backward, left and right movement;
- jump;
- interact;
- mount/dismount;
- build;
- sprint/gallop;
- manual save;
- pause.

Assigning an already-used key swaps the two bindings instead of creating an invisible conflict. Dynamic HUD prompts use the active profile and update immediately. Modifier and system labels are normalized to stable names such as `SHIFT`, `CTRL`, `ESC` and `SPACE`.

## Controller accessibility

- configurable radial dead zones;
- vertical camera inversion;
- Hold/Toggle sprint state shared by keyboard and controller;
- best-effort optional rumble with unsupported devices failing safely;
- controller Back cancels keyboard-capture mode;
- controller-only navigation remains available through pause and accessibility screens.

## Steam readiness

- `input.properties` is device-local and excluded from the packaged depot;
- CI requires the input profile, pause, accessibility and rebinding runtime classes inside the application JAR;
- existing controller-only, 1280×800 and persistence smoke-test requirements remain active;
- no Steam Deck Verified claim is made before physical Deck, Proton and Valve compatibility testing.
