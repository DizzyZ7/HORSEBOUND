# HORSEBOUND 0.4.5 — Support Diagnostics

Created by **Dimash Janibekov (DizZyZ7)**.

## Purpose

This release adds the local support information needed to diagnose failures in packaged and future Steam-distributed builds without automatic telemetry.

## Build identity

- packaged manifest includes game version and source commit;
- `HORSEBOUND.exe --version` prints the exact diagnostic build;
- the player-facing window title remains clean;
- CI launches the packaged JAR with `--version` and verifies the expected commit.

## Local crash reports

- uncaught failures produce a UTF-8 report under `%APPDATA%\HORSEBOUND\logs`;
- reports remain local and are never transmitted automatically;
- reports include build, OS, architecture, Java runtime, memory summary, thread and stack trace;
- home-directory and AppData prefixes are redacted;
- only the 10 newest reports are retained;
- failure to write a report cannot replace or hide the original crash.

## Steam distribution rules

- crash logs remain outside the install image;
- crash logs and device settings are excluded from Steam Cloud;
- CI rejects `.log`, save, settings or local Steam files inside the packaged app image;
- controller native runtime, third-party licenses, executable, JAR and bundled Java runtime remain mandatory package checks.
