# HORSEBOUND 0.4.3 — Gameplay Loop Integration

Created by **Dimash Janibekov (DizZyZ7)**.

## What changed

The active `LivingRanchScreen` now samples physical input through `InputMapper`, submits device-neutral `PlayerCommand` values to `GameSimulationLoop`, and updates gameplay at a fixed 60 Hz simulation cadence.

Fixed-step gameplay now includes:

- player movement and jumping;
- mounted horse acceleration, steering, stamina and jumping;
- wild horse wandering, fear and flee response;
- Pushik companion behavior;
- interaction, taming, mounting and fence construction;
- world time.

One-shot actions are retained until a simulation tick exists and execute exactly once even when a frame performs multiple catch-up ticks.

## Steam direction

- gameplay no longer reads keyboard key codes directly;
- keyboard/mouse is one adapter to the command contract;
- active input device is exposed to the HUD/prompt layer;
- gamepad and Steam Input adapters can reuse the same gameplay path;
- dynamic controller glyphs remain a later presentation step and are not claimed as complete yet.
