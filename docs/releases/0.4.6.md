## Purpose

0.4.6 makes display behavior, UI readability and performance measurement explicit before Homestead content increases rendering and interface load.

## Display contract

- device-local settings only;
- 1280×800 default window;
- windowed/fullscreen switching through libGDX display APIs;
- runtime fallback if a requested mode cannot be applied;
- supported window profiles: 1280×720, 1280×800, 1600×900 and 1920×1080;
- VSync remains independent from ranch saves and Steam Cloud.

## Graphics presets

- Low: MSAA off, foreground cap 60 FPS;
- Medium: 2× MSAA, foreground cap 90 FPS;
- High: 4× MSAA, foreground cap 144 FPS.

Frame caps update at runtime. MSAA changes are persisted and apply after restarting because the desktop OpenGL backbuffer must be recreated.

## UI and prompts

- centralized 1280×800 UI scale policy;
- effective readable minimum for smaller windows;
- user scale from 100% to 150%;
- main menu and Settings use scalable geometry and fonts;
- Settings remains controller-complete;
- prompt strings change between keyboard/mouse and controller families without mixing them.

## Performance overlay

The optional global overlay records a rolling 120-frame window and displays:

- average FPS;
- average frame time;
- worst recent frame time;
- current resolution;
- graphics preset;
- 800p/30 target status.

This target indicator is diagnostic only. Steam Deck compatibility still requires real hardware/Proton validation and Valve review.

## Persistence compatibility

Existing `settings.properties` files containing only VSync, mouse sensitivity and autosave remain readable. Missing new fields receive Deck-safe defaults. Ranch save format remains v3 and is unchanged.

## Verification

- extended settings round-trip;
- legacy settings compatibility;
- corrupt setting fallback;
- display normalization and profile cycling;
- Deck-native UI scaling;
- 60 FPS target pass and 20 FPS target fail;
- rolling frame sample expiry;
- keyboard/controller prompt separation;
- full existing controller, simulation, save, migration, backup and crash-report tests;
- Windows x64 `jpackage` and Steam-oriented app-image verification.
